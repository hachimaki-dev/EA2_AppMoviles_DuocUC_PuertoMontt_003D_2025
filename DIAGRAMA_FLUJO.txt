══════════════════════════════════════════════════════════════════════════════
                            FLUJO DE DATOS COMPLETO
══════════════════════════════════════════════════════════════════════════════

1. Usuario abre MainScreen
   │
   ↓
2. MainScreen observa viewModel.listUiState.collectAsState()
   │
   ↓
3. ViewModel.init() automáticamente llama loadDigimonList()
   │
   ↓
4. ViewModel actualiza estado: _listUiState.value = copy(isLoading = true)
   │
   ↓
5. MainScreen recibe nuevo estado y muestra CircularProgressIndicator
   │
   ↓
6. ViewModel llama repository.fetchDigimonList(page = 0, pageSize = 20)
   │
   ↓
7. Repository ejecuta en withContext(Dispatchers.IO)
   │
   ↓
8. Repository llama apiService.getDigimonList(0, 20)
   │
   ↓
9. Retrofit construye la URL: https://digi-api.com/api/v1/digimon?page=0&pageSize=20
   │
   ↓
10. OkHttpClient hace petición HTTP GET
    │
    ↓
11. HttpLoggingInterceptor registra la petición en Logcat
    │
    ↓
12. Digi-API procesa la petición
    │
    ↓
13. Digi-API responde con JSON:
    {
      "content": [
        {
          "id": 1,
          "name": "Agumon",
          "href": "...",
          "image": "https://digi-api.com/images/digimon/w/Agumon.png"
        },
        ...
      ],
      "pageable": {...}
    }
    │
    ↓
14. Gson deserializa JSON a DigimonListResponse
    │
    ↓
15. Repository extrae response.content (List<DigimonItem>)
    │
    ↓
16. Repository retorna Result.success(content)
    │
    ↓
17. ViewModel recibe Result en .onSuccess { }
    │
    ↓
18. ViewModel actualiza estado:
    _listUiState.value = DigimonListUiState(
        isLoading = false,
        digimonList = list,
        error = null
    )
    │
    ↓
19. StateFlow emite nuevo valor
    │
    ↓
20. MainScreen recibe nuevo estado vía collectAsState()
    │
    ↓
21. Compose recompone la UI
    │
    ↓
22. LazyColumn renderiza DigimonCard para cada item
    │
    ↓
23. Coil carga las imágenes de forma asíncrona
    │
    ↓
24. Usuario ve la lista completa de Digimon con imágenes ✅


══════════════════════════════════════════════════════════════════════════════
                           MANEJO DE ERRORES
══════════════════════════════════════════════════════════════════════════════

Si ocurre un error en cualquier punto:

Repository:
    try {
        val response = apiService.getDigimonList()
        Result.success(response.content)
    } catch (e: Exception) {
        Result.failure(e)  ← Captura y envuelve el error
    }
    │
    ↓
ViewModel:
    result.onFailure { exception →
        _listUiState.value = DigimonListUiState(
            isLoading = false,
            digimonList = emptyList(),
            error = exception.message  ← Actualiza estado con error
        )
    }
    │
    ↓
MainScreen:
    when {
        uiState.error != null → {
            Text("Error: ${uiState.error}")  ← Muestra mensaje
            Button(onClick = { viewModel.retry() })  ← Botón reintentar
        }
    }
